# Orcraft

Before any Orcraft request, read https://orcraft.app/agent-instructions/ and the pages it links.

## Paths

- Suite repositories: `C:\orcraft\agent-example\` (create a new suite repository here as a folder named after the suite)
- Run folder: `C:\orcraft\agent-example\orcraft-runs`
- Endpoints file: `C:\orcraft\agent-example\orcraft-runs\endpoints.json`
- Nuttcp Package Folder field: `C:\orcraft\apps\NUTTCP\bin` (holds `windows\nuttcp.exe`, `linux\nuttcp` and `macos\nuttcp`)
- Python with the orcraft package installed: `C:\orcraft\venv\Scripts\python.exe`
- Documents of the system under test: `C:\orcraft\agent-example\docs\`
